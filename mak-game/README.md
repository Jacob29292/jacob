# POCKETKAIJU
Prototype MVP mobile-first inspiré de Supercell.

## Installation
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Déploiement Vercel
1. Importer le dossier `pocketkaiju` dans Vercel.
2. Framework détecté: Vite.
3. Build command: `npm run build`, output: `dist`.

## Boucle de jeu
Combat -> victoire -> œuf incubé -> ouverture théâtrale -> collection -> builder.
