# M.A.K. — MY ABSOLUTE KAIJU

Prototype MVP mobile-first de tower defense en React + TypeScript + Vite.

## Lancer
```bash
npm install
npm run dev
```

## Stack
- Vite + React 18 + TS strict
- Tailwind CSS
- Framer Motion
- Zustand persist
- Howler.js

## Déploiement Vercel
Import du dossier `mak-game`, framework Vite, build `npm run build`, output `dist`.
