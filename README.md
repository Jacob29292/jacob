# Workspace Jacob

Le repo contient **2 projets** front :
- `pocketkaiju/` (ancien prototype)
- `mak-game/` (**nouveau MVP M.A.K.**)

## Pourquoi Pocket Kaiju se lance ?
Parce que tu exécutes probablement `npm run dev` dans `pocketkaiju/`.

## Lancer M.A.K.
Depuis la racine (`/workspace/jacob`) :
```bash
npm run dev
```
Ce script pointe maintenant vers `mak-game`.

Ou directement :
```bash
cd mak-game
npm run dev
```
